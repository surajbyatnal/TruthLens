About TruthLens

A CSE mini project that combines machine learning with big data analytics to flag misleading news.

Problem statement

False stories spread faster than corrections on social media and messaging apps. Readers rarely have time to verify each claim, and manual fact-checking cannot keep up with the volume of new articles. A system is needed that screens text automatically and shows readers why an article looks suspicious.

Objectives

  • Classify a news article as REAL or FAKE with a confidence score.
  • Explain each decision with the words and patterns that influenced it.
  • Process a large news dataset: clean, aggregate and analyze it.
  • Present trends in an interactive analytics dashboard.
  • Keep every article in a searchable history.

How the system works

From dataset or user input to the analytics dashboard

Big data analytics concept

Big data describes datasets too large or varied for manual inspection. News is a natural fit, because millions of articles are published every day. TruthLens applies the four classic dimensions to this problem.

VolumeTens of thousands of articles per training run.
VarietyMany sources, topics, lengths and writing styles.
VelocityNew articles arrive continuously and need quick screening.
VeracityThe central question: is the content trustworthy?

The analytics workflow has five steps, shown live on the Analytics page: load the raw dataset, clean it (duplicates, missing values, empty text), aggregate by category, source and date, run statistical analysis (mean, median, standard deviation, confusion matrix) and visualize the results. A college-scale version needs only Pandas on a laptop. Hadoop, Kafka or Spark are optional later upgrades.

What this prototype does

Everything runs in the browser so the demo works anywhere. The detector is a Naive Bayes model trained on 30 sample articles, combined with style rules (sensational phrases, ALL-CAPS, exclamation marks, attribution). The 47,000-row dataset and its accuracy figures are simulated. Replace them with a real dataset and a scikit-learn model for your final submission.

A starting point for the real backend:

# train.py
import pandas as pd, joblib
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.model_selection import train_test_split

df = pd.read_csv("news.csv").dropna().drop_duplicates()
X_tr, X_te, y_tr, y_te = train_test_split(df.text, df.label, test_size=0.2)
model = make_pipeline(TfidfVectorizer(stop_words="english", max_features=50000),
                      LogisticRegression(max_iter=1000))
model.fit(X_tr, y_tr)
print("accuracy:", model.score(X_te, y_te))
joblib.dump(model, "model.pkl")

# app.py
from flask import Flask, request, jsonify
import joblib
app, model = Flask(__name__), joblib.load("model.pkl")

@app.post("/predict")
def predict():
    text = request.json["text"]
    p = model.predict_proba([text])[0]
    return jsonify(label=model.classes_[p.argmax()], confidence=float(p.max()))
